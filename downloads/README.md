# Descarga de documentación y campaña

El ZIP contiene el snapshot de archivos versionados antes de añadir esta carpeta de descargas: README, documentación, configuración, investigación y validadores. No incluye .git, datos privados, runtime de protección implementado ni el propio directorio downloads.

[Descargar ZIP](agntia-ciberseguridad-documentacion-7-dias-2026-11-10.zip) y [SHA256](agntia-ciberseguridad-documentacion-7-dias-2026-11-10.zip.sha256). El EXPORT-MANIFEST.json interno enumera rutas/hashes y el árbol de fuente previo al empaquetado.

El archivo es reproducible mediante scripts/create_handoff_zip.py desde un checkout versionado; no es un instalador de SOC o middleware activo. Consultar GitHub/main para el SHA final de publicación, que incluye este artefacto.
