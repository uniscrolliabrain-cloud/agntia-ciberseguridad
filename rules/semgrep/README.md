# Reglas propias del piloto

Bundle original de dos reglas de evaluación dinámica en Python y JavaScript/TypeScript. Una coincidencia requiere revisión humana de la confianza de entrada; no demuestra explotación. No usa el registry ni reglas Pro. Se prueban entrada dinámica y control corregido. El perfil ignora comentarios de supresión y archivos de ignore suministrados por el repositorio. No se promete cobertura general, interarchivo o de todos los lenguajes. La licencia propia del proyecto sigue pendiente; no se copian reglas propietarias.
