# Plantilla de reporte de fase

- Fase/tareas y prioridad:
- Estado: NOT_STARTED / RUNNING / PASS / FAIL / BLOCKED / PARTIAL / DEFERRED.
- SHA/PR/árbol/configuración:
- Entorno y versiones/digests:
- Resultado observable y contrato habilitado:
- Archivos/endpoints creados o modificados:
- Comandos realmente ejecutados y exitcode:
- Tests ejecutados/pasados/fallidos/skipped, por capa:
- Gate scenarios y evidence_refs:
- Logs/artefactos sanitizados y hashes:
- Latencia/coste/recursos medidos y contexto:
- Scope/cobertura/exclusiones y datos unknown:
- Riesgos, defectos, stop conditions:
- Decisiones/ADR y revisión:
- Recuperación/rollback ejecutado o pendiente:
- Dependencias bloqueadas/siguiente paso:

No rellenar PASS, cifras o comandos por suposición. No incluir secretos ni datos de clientes. Esta plantilla es una estructura de futuro, no un resultado ya obtenido.
