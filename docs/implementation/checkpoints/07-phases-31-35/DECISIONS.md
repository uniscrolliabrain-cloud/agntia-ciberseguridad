# Decisiones

1. Schema7 aditivo para expedientes/historia/claves de origen/restricciones/linaje. Backup antes de DDL y auditoría anterior preservada.
2. Inventario por activo/finalidad con roles explícitos y unknown; cada régimen se evalúa por separado como candidato. No usar LLM como autoridad normativa.
3. Catálogo versionado por metadatos/artículos/hitos oficiales; su hash no se presenta como hash íntegro del documento legal. Ventana de revisión fuerza preparación insuficiente al caducar.
4. Mantener metadatos y referencias minimizados. Los registros de dominio no almacenan cuerpos de correo o teléfonos del mensaje.
5. Restricción debe seguir a datos derivados y al acceso directo del artefacto. Se añade linaje autenticado a evidencias de informes para cerrar también el camino de artefactos huérfanos.
6. Informes anteriores sin linaje quedan en fail-closed hasta reconciliar; no inventar un mapa ni descifrar con un bypass público.
7. Un levantamiento revisado verifica overlay vigente; no permitir que una aprobación anterior deshaga una decisión más reciente.
8. Retención/hold siguen mandando sobre purga. Backups y SAR completo permanecen explícitamente pendientes.
9. Antifraude offline y canales preconfigurados; reputación/cabeceras/deepfake sin proveedor confiable siguen unknown, aunque un mensaje diga pass.
10. Primera contención: autorización interna y laboratorio, con estado incierto persistente. Conciliar prueba de auditoría antes de reintentar; sin revocación masiva ni efectos automáticos.
11. Primeras remediaciones: dos fixtures originales, directorio privado, rutas fijas, diff redactado y scanner sin red. No interpretar una prueba estática como regresión funcional completa.
12. Mantener una PR pequeña revisable sobre el corte anterior; sin tocar repos madre, clientes, main o producción.
