# Evidencias

baseline-local.json y tests-local.json distinguen descubrimiento/passes/skips. first-local-test-failures.json conserva los fallos de fixture iniciales sin atribuirlos a cobertura real. ci.json contiene SHA/runs/jobs realmente observados; Docker separa los tests omitidos en runtime. remediation-ci.json documenta el caso con detección y retest reales de dos reglas. browser-ci.json registra capturas sintéticas sin afirmar revisión visual manual. Las referencias normativas corresponden a la observación2026-11-10, no a una verificación jurídica automática.

No guardar tokens, mensajes reales, originales o DSNs. Matrices Python, push/PR y dos iteraciones de un test Docker no aumentan el número de tests distintos.
