# Gates26–30

Todos PARTIAL: pruebas de mecanismos no acreditan una plataforma completa ni compliance universal.

- D5P2: rutas y worker agénticos heredados quedan bloqueados; policy vigente y argumentos cerrados en cada operación nominada. Falta revisión independiente y autorización organizacional real. Humanos y servicios no se convierten en agentes por inferencia.
- D5P3: procedencia, cuarentena, etiquetas, fuentes vigentes y releases de dos humanos probados. Egress solo preflight; envío deliberadamente unsupported. No hay proxy externo operativo ni modelo de flujo formal general, RAG completo o análisis multimodal.
- D5P4: handshake y peticiones HTTP reales al recurso propio con sesiones/replay/drift probados. Subconjunto limitado, sin OAuth externo ni conformidad completa. La admisión no ejecuta skills.
- D5P5: corpus original estático con8 controles benignos y16 peticiones adversariales, coste externo0. No se reproducen AgentDojo ni CaMeL, no se mide un LLM vivo, no hay adaptación ni hold-out independiente. GateG5 global no cerrado.
- D5P6: stop/resume persistente, segundo secreto, epoch, notas idempotentes y carreras/rollback probados. No MFA, proveedores externos ni deshacer trabajo ya confirmado. Humanos/servicios fuera de la clasificación agéntica y accesos directos al host siguen requiriendo inventario/operación.

ReleaseGates no cambia. No se fusiona, despliega o integra `/agente` con este corte.
