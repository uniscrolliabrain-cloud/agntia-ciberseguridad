# Recuperación de laboratorio

`PYTHONPATH=. python scripts/backup_restore_lab.py` prueba backup cifrado AES-GCM con clave externa separada, SQLite backup consistente, hashes de archivos, custodia de ciphertext, integridad y scopes de auditoría, clave incorrecta, corrupción y rechazo de sobrescritura. La API restaurada y readiness permanecen bloqueadas con RESTORE_BLOCKED. No se ofrecen comandos automáticos para quitarlo.

Alcance actual: laboratorio quiesced declarado por operador, sin jobs pending/running/reconciliation_required ni operaciones económicas started/inciertas. El bundle incluye SQLite, configuración de referencias y solo archivos cifrados de evidencia referenciados. Máximo64MiB de datos y2000 archivos; no extracción tar libre, enlaces ni traversal. Snapshots de repos y candidatos de remediación están excluidos: no sirve como recuperación productiva completa ni para reanudar scans. Las claves y tokens no se exportan. Config contiene ubicaciones y referencias sensibles dentro del cifrado.

Antes de una restauración utilizable: reconciliar restricciones de privacidad vigentes posteriores al backup, bajas/rotaciones de identidad, grants, aprobaciones externas y efectos inciertos; obtener claves externamente, verificar evidencia y preparar snapshots nuevos. La restauración antigua no demuestra revocaciones actuales. Mantener red aislada, no restaurar directamente sobre producción. La biblioteca requiere detener escritores externos: la bandera quiesced no orquesta ni demuestra que todos los procesos hayan parado.

Pruebas existentes de leases/worker, rechazo por política, fallo de DB, collector y conciliación se conservan; no se afirma un ensayo nuevo de todos los fallos de infraestructura ni un RTO/RPO contractual. Revisión independiente y backup/restauración productiva completa pendientes. El script measure_workspace.py mide API sintética vacía con CPU/RSS/disco y latencias por plan; no mide throughput de scanners ni coste mensual real.
